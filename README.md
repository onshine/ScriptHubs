# ScriptHubs

Loon / Quantumult X / Surge 签到与定时脚本合集。

## 脚本

- [linlee](linlee/) — 林里柠檬茶每日签到 + 10点鸭币兑换。R11 免维护版，token 临期自动续期。
- [bingcn](bingcn/) — Bing CN 多榜单无重复自动搜索 V6，用于 Microsoft Rewards 每日搜索。
- [lottery-query](lottery-query/) — 双色球、大乐透、福彩3D、排列三、七乐彩分段查询最近15期与今日开奖号码。

## 使用

每个脚本目录内包含：

- 主脚本 `*.js`
- Loon 插件配置 `*.plugin`（适用时）
- 独立安装说明 `README.md`

安装配置请查看对应脚本目录；建议目录内的 Raw 地址与插件地址在提交成功后使用，避免依赖临时中转载贴。

仅供学习交流。
