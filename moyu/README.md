# moyu — 摸鱼来啦（Loon 版，ScriptHubs）

每日一条「摸鱼」通知：今天几号、农历几月几日、距离周末 / 节日 / 生日还有几天，可选带黄历和节日祝福。

- **脚本版本：R1.0.0**
- 安装地址（插件）：`https://raw.githubusercontent.com/onshine/ScriptHubs/main/moyu/Moyu.plugin`
- 上游原作：`Yuheng0101/X` → `Tasks/moyu.js` v1.3.2（@yuheng）
- 农历换算：内置 `6tail/lunar-javascript` 1.7.7（MIT）

## 安装

1. Loon → 配置 → 插件 → 右上角 `+` → 粘贴上面的插件地址。
2. 在插件设置里填「节日与生日」和「提前多少天提醒」，其余保持默认即可。
3. 点插件里那条「摸鱼来啦」脚本行的 ▷ 可手动跑一次，确认通知内容。

> **更新后请删除旧插件重新添加**，Loon 会缓存远程脚本，URL 不变就一直跑旧版。

## 设置项

| 参数 | 默认 | 说明 |
|---|---|---|
| `moyu_cron` | `6 9 * * *` | 每天几点跑 |
| `moyu_festival_conf` | 13 个常用节日 | 用 `&` 分隔，格式见下表 |
| `moyu_remind_days` | `50` | 距离超过这个天数的条目不再显示（0～3660） |
| `moyu_show_almanac` | 关 | 附加今日宜忌与节气 |
| `moyu_notify_with_media` | 关 | 通知带图（未填图片时用插件图标） |
| `moyu_custom_notify_img` | 空 | 通知图片链接 |
| `moyu_debug` | 关 | Loon 日志里打印每个节日的换算结果和备注 |
| `moyu_bark_key` | 空 | 填了走 Bark 推送；留空走系统通知 |

插件里留空的项会回落到 BoxJS 的同名 key（和上游一致），所以原来 BoxJS 里的配置不会丢。

## 节日 / 生日写法

```
<内置节日>&自定义名称:日期$历法#当天的祝福
```

| 例 | 含义 |
|---|---|
| `<中秋节>` | 内置节日（农历八月十五，自动换算） |
| `某人生日:10月27日$农历` | 农历十月廿七，**每年按农历换算**（不写年份效果一样） |
| `某人生日:10月27日$农历` | 不写年份，同上 |
| `纪念日:1990年3月14日$农历#生日快乐` | 写年份也行；`#` 后面是当天才显示的祝福 |
| `生日:3月14日$阳历` | 公历，每年固定 |
| `生日:1990年3月14日$阳历$农历` | 两种历法都提醒（第二条带「（农历）」后缀） |
| `纪念日:闰2月3日$农历` | 闰月生日；没有该闰月的年份按普通同月提醒 |

历法标记：`农历` / `阴历` / `旧历` 同义，`阳历` / `公历` / `新历` 同义；不写默认阳历。
内置：`<元旦> <情人节> <妇女节> <植树节> <愚人节> <清明节> <劳动节> <青年节> <母亲节> <儿童节> <父亲节> <建军节> <教师节> <国庆节> <平安夜> <圣诞节> <春节> <元宵节> <龙抬头> <端午节> <七夕节> <中元节> <中秋节> <重阳节> <腊八节> <北方小年> <南方小年> <除夕>`

## 这一版修了什么（相对上游 1.3.2）

用户报告的问题：「这些日期我输的是农历，通知是按农历显示的吗？」——**上游答案是否**，具体有三处：

| # | 上游行为 | 结果 |
|---|---|---|
| 1 | `$农历` 分支先按**出生年**把农历换成公历，再把年份换成今年 | 农历十月廿七，于是每年都在 11/29 提醒，**跟农历无关** |
| 2 | `e.match(/(\d{4}).../)[1]` 得到的是**字符串**，却和数字年份比较 | 判断永远成立，连「不写年份」的写法也走上面那条错路 |
| 3 | 跨春节的农历日期（腊月、正月）只按公历年取 | 1 月里算出的腊月生日已经过去，会被判成「已过」直接丢掉；或者整年错位 |

本版改成：**每年按农历月日重新换算**，用「当前所处的农历年」做起点（春节前仍算上一个农历年），
拿到的公历日期早于今天就顺延到下一个农历年，**不会再出现整年错位或漏掉**。

顺带修的：

- 农历月只有 29 天时，「卅日」按廿九提醒并注明（`moyu_short_month` 可改）；
- 闰月年份缺失时自动退回普通同月，最多找 20 年（`moyu_leap_month` 可改）；
- 公历 2/29 在平年自动跳到下一个闰年；
- 日期落在法定假期内时加一句提示，并注明「节日为 X 月 X 日」；
- 正月/腊月的月份名按库自带的中文名显示（如「冬月」「腊月」），不再直接输出「11 月」；
- 当天祝福能正常显示（上游 `#祝福` 解析有时会丢）；
- 网络取文案失败也不影响通知（失败自动跳过）；
- 出错时不会因为未定义变量而静默失败。

## 已知限制

- 假期提示用的是内置的 2026 / 2027 年放假表（`HOLIDAYS`），往后年份没有表时只按日期本身提醒；官方公布新一年安排后可补一行（改 `HOLIDAYS` 即可）。
- 调休上班日不单独提醒。
- 农历「卅日」在只有 29 天的月份默认按廿九提醒（`shortMonth` 可改为 `skip` 跳过）；闰月缺失默认退回普通同月（`leapMonth` 可改为 `strict` 只在有该闰月时提醒）。这两项改的是 `readSettings()` 的默认值。

## 本地自测

`selftest.js` 只测日期引擎，不联网、不发通知：

```bash
node selftest.js        # 期望 pass=28 fail=0
```

它会按脚本里的 `moyu:lunar:*` / `moyu:engine:*` 标记，把农历库和日期引擎抽到 `/tmp` 再跑 `test-moyu.js`；也可以手工抽：农历库那段是 `let Calendar = (function () { … return __CAL__; })();`，抽出来后补上结尾的 `})();` 和 `module.exports = __CAL__;` 即可。
